# Prediccion-Titanic

Este repostorio continene un cuaderno de jupyter para mostrar un ejercicio donde se crea un modelo predictivo.

Este modelo predictivo se aplica en un Dataframe con datos de los pasajeros del Titanic y dado que no todas las filas están llenas, nos ayudamos en el modelo para que aprenda a encontrar patrones y a las personas que les haga falta el campo donde dice si sobrevivió esa persona prediga si sí lo hizo, o no, con base al entrenamiento que se le hizo.

Al final del cuaderno se puede ver que es un modelo con más del 85% de efectividad en las predicciones, lo cual lo hace un modelo aplicable a la vida real.
